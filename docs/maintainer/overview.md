# FabricOps Maintainer

This section is for repository maintainers preparing, validating, and publishing FabricOps Starter Kit releases.

Keep maintainer work focused on the small set of tasks that must happen before a release:

1. Follow the [Release Workflow](release-workflow.md) checklist.
2. Validate the [Public API & Architecture](public-api-architecture.md) boundary you are shipping.
3. Regenerate only the required [Generators](generators.md) outputs for the kind of change being released.

End-user setup and notebook walkthrough content stays in the [Guided Demo](../guided-demo.md). Maintainer-only packaging and release steps belong here.
