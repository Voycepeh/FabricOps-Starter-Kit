# FabricOps Starter Kit v1.0.0

## Release summary

v1.0.0 is the first stable release baseline for FabricOps Starter Kit.

It establishes the release-management structure for governed, quality-checked, AI-ready notebooks in Microsoft Fabric. This page intentionally focuses on the user-facing surfaces users call, copy, run, and validate.

## Upgrade impact

| Area | Impact | User action required |
| --- | --- | --- |
| Callable functions | First stable callable package baseline. | Confirm installed wheel version and review generated function reference for changed exports. |
| Notebook templates | First stable plug-and-play template baseline. | Review changed templates before replacing existing Fabric notebooks. |
| Metadata outputs | First stable metadata output documentation baseline. | Validate configured metadata writes and schema expectations before production use. |
| Documentation | Release-management, compatibility, test-matrix, breaking-change, and feature-list pages added. | Review all `Needs maintainer review` entries before publishing. |
| Compatibility | Exact runtime evidence is not asserted by this documentation PR. | Run package, wheel, Fabric notebook, and metadata validation checks before release. |
