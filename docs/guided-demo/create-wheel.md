# Create Wheel

Build the FabricOps wheel before setting up the Fabric workspace so the notebook Environment can install the same package version you will use in the demo.

## What to do

1. Follow [Create Wheel](../setup/create-wheel.md) to build the local FabricOps package.
2. Confirm the wheel appears in `dist/`.
3. Keep the wheel file available for upload when you create or update the Fabric Environment in the next step.

## Expected result

You have a FabricOps `.whl` file ready to upload to a Microsoft Fabric Environment.

Next, continue to [Create Fabric Workspace](create-fabric-workspace.md).
