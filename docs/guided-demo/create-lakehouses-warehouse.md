# Create Lakehouses / Warehouse

Create the Fabric data items that the demo will route through `00_env_config`.

## What to do

1. Create a metadata lakehouse for FabricOps metadata tables.
2. Create a source lakehouse for deterministic `demo_` source tables.
3. Create a unified lakehouse for governed pipeline outputs.
4. Create a product warehouse if you want to test warehouse output routes.
5. Record the item names so you can enter them in `00_env_config`.

## Suggested demo items

| Item | Purpose |
| ---- | ------- |
| `metadata_lakehouse` | Stores agreements, catalogue profiles, enrichment, guardrail rules, guardrail results, lineage, notebook registry, and pipeline run evidence. |
| `source_lakehouse` | Stores source tables generated by `example_pipeline_demo`. |
| `unified_lakehouse` | Stores governed outputs written by `02_pipeline`. |
| `product_warehouse` | Optional warehouse target for demos that need warehouse publishing. |

## Expected result

The required lakehouse and warehouse targets exist and can be referenced from `00_env_config`.

For configuration details, see [Template Notebooks](../how-fabricops-works/notebook-templates.md#00_env_config).
