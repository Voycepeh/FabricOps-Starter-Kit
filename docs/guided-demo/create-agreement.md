# Create Agreement

Run `01_agreement` after environment setup to capture steward, agreement, and evidence context before pipeline execution.

## What to do

1. Reuse the `CONFIG` and `ENV` values from `00_env_config`.
2. Enter demo steward details.
3. Create a public-safe data agreement for the demo workflow.
4. Save agreement evidence where needed.

## Expected evidence

The configured metadata target receives steward, agreement, and agreement evidence rows that later notebooks can select and explain.

See also: [List of Metadata Tables](../reference/metadata.md) and [List of Functions](../reference/index.md).
