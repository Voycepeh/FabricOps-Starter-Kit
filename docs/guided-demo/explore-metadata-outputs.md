# Explore Metadata Outputs

Use generated reference pages, `99_explore`, or dashboard-internal pages to inspect what the notebooks wrote.

## What to do

1. Start with the generated [List of Metadata Tables](../reference/metadata-tables/index.md).
2. Open individual metadata table pages to inspect implemented schemas and related functions.
3. Use `99_explore` for read-only troubleshooting or discovery when you need notebook-side inspection.

## Expected evidence

Users can trace agreement context, catalogue profiles, guardrail rules, runtime results, lineage, and pipeline summaries without relying on hidden notebook state.

See also: [List of Functions](../reference/index.md) and [Glossary](../reference/glossary.md).
