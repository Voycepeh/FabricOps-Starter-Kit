# Install

This page explains: how to get the wheel working in Fabric in minutes.
Use this when: you are ready to install and start using templates.
Next read: [Templates](notebook-structure.md), [Start](quick-start.md).

## Quick install

1. Download a released `.whl` (or build one with `uv build`).
2. Upload the wheel to your Fabric Environment custom libraries.
3. Attach that Environment to your notebook runtime.
4. Restart session/runtime if Fabric prompts you.
5. Verify import: `import fabricops_kit as fsk`.
6. Open [Templates](notebook-structure.md) and run [Start](quick-start.md).
