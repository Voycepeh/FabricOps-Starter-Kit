# FabricOps Starter Kit

FabricOps, short for **Fabric Operations**, is a plug-and-play, lightweight starter kit that helps Governance, Data engineering, and AI and BI analytics teams quickly set up and adopt an out-of-the-box workflow within Microsoft Fabric.

It combines a Python package containing helper and orchestrator functions, standardized Python notebook templates, a shared metadata model, and a guided demo.

By standardizing this workflow, FabricOps gives both people and AI-assisted analytics work a consistent starting point, with essential metadata and Governance processes built directly into engineering pipelines. FabricOps does not provide its own AI model or agent framework.
