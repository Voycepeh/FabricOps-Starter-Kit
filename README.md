# FabricOps Starter Kit

**Plug-and-play Data Engineering and Governance for Microsoft Fabric.**

<div align="center">

[![Documentation Home](https://img.shields.io/badge/Documentation-Home-blue?style=for-the-badge)](https://voycepeh.github.io/FabricOps-Starter-Kit/)

</div>

FabricOps (Fabric Operations) is an open-source starter kit that helps data teams build, govern, and operate reliable data pipelines in Microsoft Fabric.

It combines reusable PySpark pipelines, executable Data Contracts, and centralized metadata management into one integrated engineering workflow.

Rather than building governance and engineering processes separately, FabricOps brings them together so teams can deliver trusted data faster and more consistently.

## What FabricOps provides

| Capability | What it provides |
| --- | --- |
| **Plug-and-play data pipelines** | Reusable, environment-aware PySpark orchestration for full and incremental reads, plus overwrite, append, SCD1, and SCD2 writes. |
| **Governance as code** | Versioned Data Contracts with validation and enforcement integrated into engineering workflows. |
| **Data quality and guardrails** | Freshness, schema, and Data Quality checks, alongside sensitive data treatment before writes. |
| **AI-assisted governance** | Optional suggestions for sensitive data classification and translating business rules into executable Data Quality rules. |
| **Centralized metadata** | Shared catalogue, profiling, lineage, contract, and validation metadata. |
| **Effective data access** | Visibility into effective access across Fabric workspace roles, SQL permissions, and OneLake security. |

FabricOps includes reusable Python functions, notebook templates, metadata schemas, and guided examples.
